# Order Tracking Screen

A responsive mobile-first order tracking screen built for a frontend practical assessment.

### Tech Stack
- React
- Vite
- Tailwind CSS
- DaisyUI
- React Icons

### Features
- Order tracking timeline
- Delivery status updates
- Delayed order state
- Delivered but not received state
- Tracking unavailable state
- Responsive mobile UI
- Contact support interaction
